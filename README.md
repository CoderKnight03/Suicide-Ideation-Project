# Suicide Ideation from Social Media using Large Language Models and Human-in-the-Loop Automation

Problem Statement:  
In today’s fast-paced, ambitious world, many individuals face a lot of difficulties including anxiety, stress, economical loss, relationship problems and various other psychological problems. The overwhelming nature of these problems sometimes compel the individuals to take extreme measures including self-harm and ultimately suicide.


Proposed Solution: 
In order to counter this, we propose a web-based interface similar to other social media platforms, wherein the text-based posts of the individuals will be analyzed via a monitoring layer. This would intend to understand the user’s mental state, and the same will accordingly be categorized as Suicidal or Not-Suicidal. If a suicidal tendency is detected, an immediate alert will be sent to the individual’s guardians and authorities, enabling timely intervention and avoiding any potential risks. The customized data for this approach is pooled from various publicly available social media-based datasets.
